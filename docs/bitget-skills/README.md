# Bitget Skills

This folder documents how each Bitget Agent Hub skill contributes to the strategy.

Core first-version skills:

- `news-briefing`
- `macro-analyst`
- `technical-analysis`

Auxiliary first-version skills:

- `sentiment-analyst`
- `market-intel`

The first version uses these as official Bitget-provided signal sources. It does not build a custom crawler or custom market data system.
