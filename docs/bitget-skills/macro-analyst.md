# macro-analyst

Purpose: judge whether the macro environment supports or blocks risk-taking.

First-version focus:

- Fed stance.
- Interest-rate environment.
- DXY.
- VIX.
- Nasdaq / S&P 500 risk appetite.
- CPI / FOMC event context.

Macro can act as a hard filter. If the environment is clearly risk-off, the strategy should not force a bullish view from news alone.
