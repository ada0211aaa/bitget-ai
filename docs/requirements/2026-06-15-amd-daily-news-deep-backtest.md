# AMDUSDT 全量日线新闻策略深测需求文档

## 1. 基本信息

- 需求名称：AMDUSDT 全量日线新闻策略深测
- 所属项目：Bitget AI Hackathon，美股 AI 交易赛道
- 项目路径：`/Users/ada/Documents/bitget ai`
- 文档状态：草案，待用户确认后进入实施计划
- 创建日期：2026-06-15
- 需求来源：用户希望把当前短周期回测升级为更适合长线的日线策略，并明确回测起止时间、新闻覆盖区间和买卖逻辑

## 2. 背景

当前页面已经能展示多票回测结果和单票运行详情，但现有回测主要基于较短的 `15m` K 线窗口。用户希望先用一只股票做深测，把策略从短线噪音转为更适合长线的“日线 K 线 + 新闻事件”模式。

本轮已确认：

1. 第一版单票深测标的为 `AMDUSDT`。
2. 周期使用 `1d` 日线。
3. 不再死卡“最近 1 年”，而是优先使用 `AMDUSDT` 可获取的全部日线历史。
4. 第一版为保证新闻质量和页面可解释性，最多先取最近 5 年日线。
5. 新闻策略只在 K 线和新闻都有覆盖的重叠区间内计算，页面必须把覆盖区间讲清楚。

## 3. 目标

1. 为 `AMDUSDT` 拉取并落盘日线 K 线数据。
2. 回测区间优先覆盖 `AMDUSDT` 可获取的全部日线历史；第一版上限最近 5 年。
3. 为回测区间内的新闻 / 事件信号落盘，并与交易日对齐。
4. 使用“新闻优先 + MA20/MA50 技术确认 + MA120 大趋势过滤”的长线策略口径。
5. 页面明确展示：
   - K 线覆盖区间
   - 新闻覆盖区间
   - 有效新闻策略回测区间
   - 数据源
   - AMDUSDT 日线价格走势曲线
   - 每次买入 / 卖出 / 观望的原因
6. 继续保持 backtest-only：不下单、不查账户、不展示密钥。

## 4. 非目标

1. 本轮不做真实交易、自动下单、账户读取、余额读取、持仓读取。
2. 本轮不扩展到多票；只做 `AMDUSDT` 单票深测。
3. 本轮不引入完整数据库系统；优先使用 JSON / CSV 文件落盘。
4. 本轮不搬运 `daily_stock_analysis-main` 的完整系统架构。
5. 本轮不构建大型新闻爬虫；优先使用 Bitget 官方技能口径和现有公开新闻降级源。
6. 本轮不承诺实盘收益，不把回测结果描述成投资建议。
7. 本轮不记录完整私有实盘策略参数或任何密钥。

## 5. 专家口径

本轮采用美股量化回测专家视角：

1. 先把数据区间、事件时间、信号生成时间讲清楚，再谈策略收益。
2. K 线历史和新闻历史可能覆盖不一致，不能把没有新闻覆盖的区间伪装成完整新闻策略回测。
3. 长线策略应使用日线，减少 `15m` 噪音。
4. 技术指标不要堆太多，第一版只使用可解释的均线和 RSI 过滤。

| 区间 | 含义 |

如果新闻覆盖不足，页面必须明确提示，而不是只显示收益率。

## 7. 策略口径

### 7.1 总原则

1. 新闻是门票。
2. 技术是确认。
3. MA120 是大趋势过滤。
4. 没有新闻覆盖的日期，不产生新闻驱动买入。
5. 长线策略宁可少交易，也要把每次交易原因讲清楚。

### 7.2 指标角色

| 指标 | 角色 | 用法 |
| --- | --- | --- |
| MA20 | 进场触发线 | 判断新闻出来后价格是否开始走强 |
| MA50 | 中期趋势确认线 | 判断不是一日游 |
| MA120 | 大趋势过滤线 | 判断是否处在中长期趋势可接受区域 |
| RSI | 追高过滤 | 避免明显超买后追入 |

### 7.3 买入条件

买入必须满足：

1. 当前有效新闻窗口内有 `强利好` 新闻。
2. 新闻方向为看多。
3. 当日完整收盘价 `close > MA20`。
4. `MA20 > MA50`。
5. 如果 MA120 已经可用，价格不能明显弱于 MA120。
6. RSI 不处于明显超买区。
7. 当前没有持仓。

### 7.4 卖出条件

卖出满足以下任一情况：

1. 出现 `强利空` 新闻，并且技术面转弱。
2. 收盘价跌破 MA50。
3. 收盘价跌破 MA120，视为大趋势破坏。
4. 触发止损或最大回撤保护。

### 7.5 观望条件

以下情况应记录为观望：

1. 有强利好新闻，但价格仍未站上 MA20。
2. 有强利好新闻，但 MA20 仍低于 MA50。
3. 有强利好新闻，但价格明显弱于 MA120。
4. 有普通利好新闻，但未达到强利好门槛。
5. 技术面走强，但没有新闻门票。
6. 新闻覆盖缺失或新闻时间晚于决策日。

## 12. 风险与处理

| 风险 | 影响 | 处理方式 |
| --- | --- | --- |
| Bitget AMDUSDT 日线历史不足 | 回测区间短 | 页面明确提示，并可把公开 AMD 现货数据作为参考展示但不混同 |
| 新闻覆盖不足 | 新闻策略有效区间短 | 单独展示新闻覆盖区间和有效回测区间 |
| MA120 过严 | 可能错过底部反转 | 第一版作为过滤 / 观望原因，不作为所有买入的绝对硬门槛 |
| 新闻分类粗糙 | 强利好 / 强利空可能误判 | 保留 `reason` 字段和原文链接，方便人工核验 |
| 交易太少 | 页面动作少 | 保留每日观望记录，展示为什么不交易 |
