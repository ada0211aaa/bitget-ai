# AI 新闻强度 + MA20/MA50 日线策略需求文档

## 背景

当前外部美股日线回测已经能拉取并落盘多只股票价格，但不带 `--events` 时只用短线技术指标产生买卖，页面会出现“有收益、有交易次数，但没有决策明细和买卖点”的割裂感。带 `--events` 时会生成观望决策，但现有保守策略仍使用短线技术确认，且新闻字段不足以表达 AI 判断强弱。

本轮要把策略改成更符合用户目标的版本：新闻是买入门票，AI/Bitget skill 负责判断新闻强弱，MA20/MA50 负责日线技术确认，页面必须能解释每一次买入、卖出、观望。

## 目标

1. 扩展新闻事件结构，支持 AI/Bitget skill 的结构化判断字段。
2. 优先读取 `data/bitget-skills/*.json` 中的 Bitget Agent Hub skill 导出结果。
3. 当 Bitget skill 没给完整字段时，用现有关键词规则做降级判断。
4. 日线技术确认从短线 `MA3/MA5` 改为 `MA20/MA50`，并可展示 `MA120` 大趋势。
5. 买入规则改为“强利好新闻 + 股票直接相关 + 技术确认 + 不追高”。
6. 卖出规则使用用户确认的 A 方案：强利空新闻、跌破 MA50、或从持仓最高价回撤 12%，任一满足则卖出。
7. 即使观望，也必须写入 `decision-records.json`，说明为什么没有买。
8. 所有真实买卖都必须生成 `markers.json`，图表上能看到买入/卖出点。

## 非目标

1. 不让 AI 直接下买卖指令。
2. 不接真实下单，不查账户，不读取密钥。
3. 不做高频、分钟级策略。
4. 不优化参数到收益最大化，避免为了比赛演示过拟合。
5. 不一次性接入多个外部 AI API；第一版以 Bitget skill 导出为主，关键词降级为辅。

## 新闻结构化字段

`NewsEvent` 需要支持以下新增字段：

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| `strength` | `strong` / `medium` / `weak` | 新闻强度 |
| `topic` | `earnings_guidance` | 新闻主题 |
| `time_horizon` | `short_term` / `medium_term` / `long_term` | 影响周期 |
| `stock_relevance` | `direct` / `indirect` / `weak` | 和股票本身的相关性 |

如果 Bitget skill JSON 缺少这些字段：

- `strength` 从情绪、置信度和关键词降级推断。
- `stock_relevance` 默认 `direct`，但公开新闻仍需通过 ticker/company alias 过滤。
- `topic` 默认 `unknown`。
- `time_horizon` 默认 `short_term`。

## 策略规则

### 买入

满足全部条件才买入：

1. 最近可用新闻窗口内存在强利好新闻。短周期使用 24 小时窗口；日线使用 72 小时窗口，避免周五盘后新闻到周一开盘被漏掉。
2. `stock_relevance = direct`。
3. `confidence >= 0.7`。
4. 收盘价高于 MA50。
5. MA20 高于 MA50，或 MA50 斜率向上。
6. RSI 小于 75，避免明显追高。
7. 当前没有持仓。

### 卖出

用户已确认 A 方案，满足任一条件则卖出：

1. 出现强利空新闻。
2. 收盘价跌破 MA50。
3. 从持仓后最高价回撤达到 12%。

### 观望

以下情况必须写入观望记录：

1. 没有新闻门票。
2. 新闻不够强。
3. 新闻强但股票相关性不是 `direct`。
4. 新闻强但技术未确认。
5. RSI 过高，避免追高。
6. 已有持仓但没有卖出条件。

## 页面要求

1. 首页仍显示多票行情列表。
2. 单票详情必须显示交易决策明细。
3. 决策明细需要显示：
   - 新闻强度
   - 新闻方向
   - 主题
   - 影响周期
   - 股票相关性
   - 技术确认
   - 冷却/风控状态
   - 决策原因
4. 图表上所有真实买卖必须有 marker。
5. 点击 marker 必须定位到对应决策行。

## 验收标准

| 编号 | 验收项 | 验证方式 | 通过标准 |
| --- | --- | --- | --- |
| AC-1 | Bitget skill 字段可读取 | 单元测试 | `strength/topic/time_horizon/stock_relevance` 被写入事件 |
| AC-2 | 缺字段可降级 | 单元测试 | 旧 JSON 不报错，并能推断新闻强度 |
| AC-3 | MA20/MA50 买入规则 | 单元测试 | 强利好 + MA20>MA50 + close>MA50 + RSI<75 触发买入 |
| AC-4 | RSI 过热不追 | 单元测试 | RSI>=75 时强利好也观望 |
| AC-5 | 强利空卖出 | 单元测试 | 持仓时强利空触发卖出 |
| AC-6 | 跌破 MA50 卖出 | 单元测试 | 持仓且 close<MA50 触发卖出 |
| AC-7 | 回撤 12% 卖出 | 单元测试 | 持仓后从最高价回撤 12% 触发卖出 |
| AC-8 | 决策与 marker 完整 | CLI 测试 | 有真实买卖时 `decision-records.json` 和 `markers.json` 均有对应记录 |
| AC-9 | 页面显示 AI 判断字段 | 静态/UI 测试 | 明细表包含主题、影响周期、股票相关性 |
| AC-10 | 日线新闻窗口覆盖周末 | 单元测试 | 周五盘后强新闻可进入下一个交易日日线判断 |

## 安全边界

本功能只影响本地回测、落盘和页面展示。禁止接入真实交易执行、账户查询、实盘密钥或后台任务。
