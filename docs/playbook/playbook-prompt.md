# Playbook Prompt

Use this file to draft the natural-language strategy prompt for Bitget Playbook.

The prompt should describe:

- Strategy theme.
- Candidate assets: Bitget-listed stock USDT perpetual contracts such as `NVDAUSDT`, `MSFTUSDT`, `GOOGLUSDT`, `AMDUSDT`, and `METAUSDT`.
- Signal sources.
- Hard risk filters.
- Daily cadence.
- Five-view output style.
- Backtest expectation.

The prompt should not claim that the strategy trades traditional US stock spot assets. It should describe the asset scope as Bitget stock futures / stock USDT perpetual contracts.

Use `<PLAYBOOK_API_KEY>` as a placeholder only if a key must be referenced in an example.
